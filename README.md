# 隔声试验数据交付复核工具

声学实验室向外部复核方交付隔声试验数据的网页工具：从上传的 SQLite 库中勾选试验、
剔除个别异常读数，沿对照/校准引用自动补齐所需记录，确认预览后下载 SQLite 子库。

## 运行

```bash
docker compose up --build
# 打开 http://localhost:8000
```

本地开发（Python 3.11+）：

```bash
pip install -r requirements-dev.txt
python3 scripts/make_sample_db.py sample.db   # 生成演示库
uvicorn app.main:app --reload
```

运行测试：`pytest`

## 数据库结构约定

上传的 SQLite 库需包含四张表（关键列名固定，其余列任意）：

| 表 | 关键列 | 说明 |
| --- | --- | --- |
| `groups` | `id`, `name` | 试验组 |
| `calibrations` | `id`, `device` | 校准记录 |
| `tests` | `id`, `group_id→groups`, `calibration_id→calibrations`(可空), `name` | 试验 |
| `readings` | `id`, `test_id→tests`, `calibration_id→calibrations`(可空), `control_reading_id→readings`(可空), `kind` | 读数；`control_reading_id` 为对照读数引用，允许跨组 |

## 交付规则

1. 交付所选试验中未被剔除的全部读数；
2. 沿对照引用（`control_reading_id`）与校准引用（`calibration_id`，读数级与试验级）
   补齐所需记录；对照读数允许跨组互引；
3. 跨到未勾选的组时，只带入沿引用找到的读数，以及这些读数所属的试验、
   试验所属的组（维持外键完整所必需）和引用到的校准记录；
4. 引用悬空（目标不存在）或指向已剔除读数时，预览页展示完整引用链并**阻止下载**；
5. 子库建表语句复用源库 DDL 原文，主键、外键约束、索引原样保留，行按原主键写入，
   导出后执行 `PRAGMA foreign_key_check` 校验。

## 使用流程

1. **上传**：选择实验室导出的 SQLite 库（结构不符会给出具体缺失项）；
2. **选择**：按组勾选要交付的试验，可在所选试验下勾选要剔除的异常读数；
3. **预览**：查看交付汇总、跨组带入的读数及其引用链；若存在引用冲突，
   展示每条冲突的完整引用链，下载按钮禁用；
4. **下载**：确认后下载 `*_subset.db`。下载前服务端会重新解析一次，
   若状态已变化产生冲突则返回 409 拒绝。

## 工艺差可估计性分析

两种装配工艺常在不同舱室试验。选择页 / 预览页的「工艺差分析」入口用于判断：
**已有读数能否把工艺差与试验条件（舱室、装夹方式）分开**。

1. **上传标注表**：CSV 按库内读数编号标注工艺、舱室、装夹方式；
2. **选择频点与两种工艺**：频点下拉框只列有标注读数的频点，
   工艺下拉框只列该频点下有标注的工艺；
3. **查看结论**：拟合使用该频点**全部**已标注读数（含其他工艺的读数），
   按 `y = μ + α_工艺 + β_舱室 + γ_装夹` 加性模型做最小二乘：
   - 若所有最优解给出相同的工艺差 → 显示差值（dB）与参与读数；
   - 否则给出两组**同为最优、逐条拟合值相同、工艺差却不同**的系数，
     并指出造成混杂的系数调整方向（通常因两种工艺的标注在舱室/装夹
     组合上不交叉），此时工艺差无法与试验条件分开。

### 标注 CSV 格式

```csv
reading_id,process,cabin,fixture
1001,甲,舱A,夹具X
1002,乙,舱B,夹具X
```

- 表头也接受中文 `读数编号,工艺,舱室,装夹方式`；多余列忽略；
  编码 UTF-8（兼容 BOM）或 GB18030；
- **整份更正**：每次上传整体替换旧表，版本号递增；分析结论与参与读数
  始终取自同一版本（结果页标注所用版本号）；
- **拒收规则**：含库中不存在的读数编号、同一编号标注冲突、字段为空或
  列缺失时，整份拒收并保留原表；完全相同的重复行自动去重；
- 旧库缺 `frequency_hz` 或 `level_db` 列时，分析页会说明原因；
  已标注但 `level_db` 为空的读数不参与拟合并单独列出。

### 演示样例（补标后从无法估计变为可估计）

```bash
python3 scripts/make_analysis_sample.py        # 生成到 ./analysis_sample/
```

1. 上传 `analysis_sample.db`，进入「工艺差分析」；
2. 上传 `annotations_v1.csv`（甲只在舱A、乙只在舱B）→ 选 500 Hz、工艺甲/乙
   → 结论：**无法估计**，页面给出两组同为最优、拟合值相同但工艺差相差 1 dB
   的系数及混杂方向；
3. 整份替换为 `annotations_v2.csv`（补标读数 1006：工艺乙在舱A 的补测）
   → 同一查询变为**可估计**：工艺差 甲 − 乙 = 3.1 dB，参与读数 6 条。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DATA_DIR` | `./data`（容器内 `/data`） | 上传文件与子库的工作目录 |
| `MAX_UPLOAD_MB` | `200` | 上传大小上限 |

## 已知限制

- 会话保存在单进程内存中，重启后需重新上传；上传文件保留在 `DATA_DIR`，
  需运维定期清理（未实现自动清理）；
- 未做多用户隔离与鉴权，仅供实验室内网使用；
- 表名/关键列名固定，如实验室库结构不同需先适配（见 `app/core.py` 顶部约定）；
- 工艺差分析：频点按 `frequency_hz` 精确值匹配；标注表随会话保存、
  重启即失效；最小二乘用分数精确运算，规模按"每频点数十至数百条读数、
  若干因素水平"设计，未针对更大规模优化。
